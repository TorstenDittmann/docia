# Security Policy

## Supported versions

Security fixes are provided for the latest stable release of docia. Before 1.0.0, fixes are
published in the next available release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for the
[docia repository](https://github.com/TorstenDittmann/docia/security/advisories/new).

Include reproduction steps, affected versions, and the potential impact. Please do not open a
public issue for an undisclosed vulnerability. You can expect an initial response within seven
days.
